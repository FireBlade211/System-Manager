# System Manager
**System Manager** is an extensible tool that brings Windows utilities together in one place and lets you install plugins to add more tools.

## System Requirements
- **.NET Framework** 4.5.2 runtime
- **Windows Vista** SP2 or **Windows 7** and later

## Installation
1. Download the latest ZIP file from the [Releases](https://github.com/FireBlade211/System-Manager/releases) page.
2. Extract the file.
3. Run `System Manager.exe`.

## Plugins
**System Manager** allows developers to extend it by creating plugins.

- To publish your plugin, see the [System-Manager-Plugins](https://github.com/FireBlade211/System-Manager-Plugins) repository.
- To learn how to create a plugin, see the documentation by selecting **Help** -> **Plugin Documentation** inside **System Manager**.
