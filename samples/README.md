# System Manager Plugin Samples
This folder contains samples that you can use as reference in your **System Manager** plugins.

## How to use samples
- If you came here from the repository, you can follow the instructions in each sample's README file.
- If you're here from the ZIP sample package, copy the plugin DLLs to the `plugins` folder under your **System Manager** installation directory.

## Source code
The source code for each sample is available in the [repository](https://github.com/FireBlade211/System-Manager/tree/main/samples).
