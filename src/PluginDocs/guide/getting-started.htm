Getting Started

This guide will help you create your first plugin.

NOTE: This guide assumes you are using Visual Studio.

Creating the project

  1. Open Visual Studio.
  2. Click Create Project.
  3. From the list of templates, select Class Library (.NET Framework).
  4. Name your project and specify a location to save it in.
  5. From the list of versions, select .NET Framework 4.5.2 or an earlier version.
  6. Click Finish to create the project.

Setting up the project

  1. In Solution Explorer, right-click your project and select Properties.
  2. Inside the Project Properties menu, go to Build Actions

  3. Inside Post-Build Actions, specify the following command-line string:

    
IF NOT EXIST "PATH_TO_SYSTEM_MANAGER\plugins" MKDIR "PATH_TO_SYSTEM_MANAGER\plugins"
COPY "$(TargetPath)" "PATH_TO_SYSTEM_MANAGER\plugins\$(TargetFileName)" /Y
IF "$(ConfigurationName)" == "Debug" COPY "$(TargetDir)$(TargetName).pdb" "PATH_TO_SYSTEM_MANAGER\plugins\$(TargetName).pdb" /Y

    Make sure to replace PATH_TO_SYSTEM_MANAGER with the directory of your System Manager installation.

  4. Set the Run the post-build event setting to When the build updates the project output.
  5. Close the Project Properties.
  6. In Solution Explorer, right-click References, and select Add Project Reference.
  7. In the Add References dialog, go to the Browse tab, and click Browse.
  8. Find the directory of your System Manager installation, and select FireBlade.SystemManager.Plugin.dll.
  9. (OPTIONAL) To make developing plugins easier, System Manager provides a helper DLL. To include the DLL, click Browse again, and select FireBlade.SystemManager.Helpers.dll.
  10. Click OK.

Implementing contracts

NOTE: If you don't know what contracts are yet, please see the Contracts page.

  1. Create a new C# code file. Name it MyPlugin.cs.
  2. At the top of the file, add the following statement: using FireBlade.SystemManager.Plugin;
  3. Define a new class called MyPlugin.
  4. Make sure the class implements the IPlugin interface.

  5. Inside the QueryContract function, define a switch statement as follows:

    
switch (contractIdentifier)
{
   case ContractIdentifiers.PluginInfoContractIdentifier:
         return new MyPluginInfo();
   case ContractIdentifiers.PluginTreeContractIdentifier:
         return new MyPluginTree();
}

    NOTE: Right now, this will cause 2 errors. This is because the classes referenced in this code snippet do not exist. We will create these classes in the next section.

Implementing the Info and Tree contracts

  1. Create a new code file named MyPluginInfo.cs.
  2. Inside the code file, add the same using statement as before.
  3. Define a new class named MyPluginInfo.
  4. Make sure the class implements the IPluginInfoContract interface.
  5. Inside the Name property, specify "Hello, World!". Inside the Description property, specify "This is a custom plugin!"
  6. For now, return null from the QueryContract function.
  7. Create a new code file named MyPluginTree.cs.
  8. Inside the code file, add the same using statement as before.
  9. Define a new class named MyPluginTree.
  10. Make sure the class implements the IPluginTreeContract interface.
  11. Inside the GetNodes function, set the parentId to root and return an array of IPageNodeContracts, like this: return new IPageNodeContract[] { new MyPageContract() };

Defining pages

  1. Create a new code file named MyPageContract.cs.
  2. Inside the code file, add the same using statement as before.
  3. Define a new class named MyPageContract.
  4. Make sure the class implements the IPageContract interface (not to be confused with IPageNodeContract)
  5. Inside the Id property, specify "HelloWorldSample.TestPage".
  6. Inside the DisplayName property, specify "Hello, World!".
  7. Inside the Description property, specify "This is a sample page.",
  8. Inside the CreateContent function, return the following UI: 
    
        public UserControl CreateContent() => new UserControl
        {
            Controls =
            {
                new Label
                {
                    Dock = DockStyle.Fill,
                    TextAlign = ContentAlignment.MiddleCenter,
                    Text = "Hello, World! This is a sample page from a plugin."
                }
            }
        }
  9. From the QueryContract function, return null.

Build and Test

  1. Compile the project.
  2. Open your System Manager installation directory and navigate to the plugins folder.
  3. Verify that your plugin DLL was successfully copied to the directory.
  4. Run System Manager.
  5. Check that your new Hello, World! page appears under the Home node.
  6. Navigate into your page and test that the UI is created correctly. The page should say "Hello, World! This is a sample page from a plugin."

You have successfully created your first plugin. Note that the page currently displays the icon of the previous page; see the documentation for IPageContract for more details. To debug your plugin, see the Debugging Plugins page.
