Sideloading

Sideloading allows you to load plugins that were not obtained from the official plugin repository. Before sideloading, please read the following warning:

  • Plugins are loaded into the same application domain (AppDomain). This means they run in the same security context as System Manager itself and are not isolated. Make sure you trust the plugin you want to sideload before sideloading it.

To sideload a plugin:

  1. Find the DLL file for the plugin.
  2. Navigate to your System Manager installation directory.
  3. Open or create the plugins subdirectory.
  4. Copy your plugin's DLL file into the plugins directory.

When debugging a plugin, you may want to sideload with symbols. Simply copy your plugin DLL's symbol file next to the plugin in the plugins directory.
