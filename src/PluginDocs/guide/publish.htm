Publish your plugin

To publish your plugin to the official plugin repository:

  1. Fork the System-Manager-Plugins repository.
  2. Clone your fork of the repository to a local folder using Git.
  3. Inside the plugins subfolder, add your plugin DLL and rename it to PluginID.dll, where PluginID is a unique string that identifies your plugin.
  4. Create a new file next to the DLL named PluginID.dll.json. This file will contain your plugin manifest, which allows the Plugin Gallery to identify the plugin before downloading it.

  5. Inside the plugin manifest, paste the following JSON structure and replace the values in each field as necessary:

    
{
   "name": "My Plugin",
   "description": "Sample description",
   "author": "Creator of this plugin",
   "version": "1.0"
}

    NOTE: The version number can be in one of 4 different formats: an incrementing number, MAJOR.MINOR, MAJOR.MINOR.PATCH, and Windows-style (MAJOR.MINOR.BUILD.REVISION). You cannot change between versioning styles after your plugin has been uploaded, even if you want to update it.

  6. Commit your changes with a descriptive commit message.
  7. Push your local changes to your fork repository.
  8. Create a new Pull Request (PR) from your fork repository to the main System-Manager-Plugins repository, and fill out the PR template as necessary.
  9. Wait until your PR gets merged or I respond to it. I'm busy and can't keep responding to everyone at once, so you might get unlucky. I'm sorry.
