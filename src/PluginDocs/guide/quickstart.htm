Quickstart Guide

NOTE: This guide assumes you are using Visual Studio.

  1. Create a new Visual Studio Class Library project.
  2. Make sure to choose .NET Framework 4.5.2 or an earlier, comaptible version.
  3. Create the project.
  4. Add a Post-Build Action similar to the following: IF NOT EXIST "..\System Manager\plugins" MKDIR "..\System Manager\plugins" COPY "$(TargetPath)" "..\System Manager\plugins\$(TargetFileName)" /Y IF "$(ConfigurationName)" == "Debug" COPY "$(TargetDir)$(TargetName).pdb" "..\System Manager\plugins\$(TargetName).pdb" /Y

    Adjust the paths to point to your System Manager installation accordingly.

  5. Add FireBlade.SystemManager.Plugin.dll and optionally FireBlade.SystemManager.Helpers.dll from your System Manager installation as a reference in your project.
  6. Define an implementation of the IPlugin contract and implement other contracts as required.
