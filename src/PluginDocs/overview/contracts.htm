Contracts

Contracts allow a plugin to communicate with System Manager. Every contract is defined as an interface that inherits from the IContract interface and adds additional methods and properties on top.

Each plugin contains one instance of the IPlugin contract. If a plugin provides more than one, only the first one will be used and the others will be dropped, based on .NET Framework's load order.

The IContract interface, which all other contracts inherit from, provides the QueryContract function. This function allows you to give additional contracts back to System Manager. The contracts that a particular contract can return from QueryContract are listed under the This contract can implement section on each contract's API page. The contract identifiers for every contract are in the ContractIdentifiers class in the FireBlade.SystemManager.Plugin namespace.

This contract-based model ensures backwards compatibility, allowing an older plugin to work on newer versions of System Manager, as it only has to implement the contracts it uses.
