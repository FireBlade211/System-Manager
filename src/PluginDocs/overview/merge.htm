Menu/Toolbar Merging

If your page contains a MenuStrip, System Manager will automatically merge the first MenuStrip it finds when the user navigates to your page, based on Windows Forms (WinForms) merging rules. The MenuStrip that was found will then be removed from your page, to ensure that there are no duplicate commands.

If your page contains a ToolStrip, System Manager will automatically find the first ToolStrip, insert all of your items into the System Manager global toolbar, and then remove the ToolStrip from your page.

These rules allow your page to directly integrate with System Manager, allowing the user to easily access both System Manager commands, as well as your page commands in one place. (Note: System Manager commands are not on the toolbar, however the merging is still provided for your convenience).
